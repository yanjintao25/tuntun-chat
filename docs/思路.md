# 项目思路与进度

## 整体思路

飞书侧：企业自建应用 + 事件订阅（Webhook 或长连接），接收用户发给机器人的消息。

云服务器 / 本地：Node 服务提供：

- 飞书事件接收（验签、解密、3 秒内先回 200）
- 大模型意图识别与对话
- 可配置能力：日程、待办、每日总结
- 后台配置 API（开关与参数）

技术栈：Node.js + TypeScript、Express、`@larksuiteoapi/node-sdk`、OpenAI 兼容 API、SQLite、`node-cron`。

### 待办提醒已实现的能力

1. 用户聊天创建待办（LLM 抽标题 + 时间 → `todos` 表）
2. 查询待办列表、标记完成、取消
3. 按 `reminderMinutes` 计算提前提醒时间
4. 每分钟扫描，主动推送提前提醒与到期提醒
5. 推送失败自动重试（不提前标记已发送）

详见 [DATABASE.md](./DATABASE.md)、[ARCHITECTURE.md](./ARCHITECTURE.md)。

## 踩坑记录

- 飞书必须在「权限管理」开齐 `im:message` **接收与发送**权限，否则收不到消息或待办提醒发不出去。
- 长连接模式：须先启动 `ws-client` 建立连接，才能在开放平台保存「使用长连接接收事件」配置。

## 本地 / 部署速查

```bash
npm install
cp .env.example .env   # 填飞书凭证、大模型 API
npm run dev:ws         # 长连接（推荐）
# 或 npm run dev       # Webhook
```

- 配置开关：`GET/PUT http://localhost:3000/admin/config`
- 待办测试：对机器人说「提醒我明天 9 点交报告」「我有哪些待办」

部署细节见 [DEPLOY.md](./DEPLOY.md)。
