整体思路
飞书侧：用企业自建应用 + 事件订阅（Webhook），接收用户发给机器人的消息。
云服务器：跑一个 Node 服务，提供：
接收飞书事件的接口（验签、解密、3 秒内先回 200）
调用大模型做意图识别和回复
可配置的「能力」：日程、待办、每日总结等
后台配置 API，用来开关和调参数
项目里已生成的内容
内容	说明
docs/DESIGN.md	架构说明、飞书配置步骤、技术选型、目录与流程
docs/DEPLOY.md	云服务器部署步骤（Nginx、PM2、HTTPS）
src/	后端代码：飞书事件、LLM、功能模块、配置存储、管理 API
.env.example	环境变量示例（飞书 App ID/Secret、大模型 API 等）
技术栈：Node.js + TypeScript、Express、@larksuiteoapi/node-sdk、OpenAI 兼容 API、SQLite 存配置。
可配置功能（后台可开关/调参）：
日程管理：开关、默认日历（接入飞书日历时可创建/查询日程）
待办提醒：开关、提前多少分钟提醒（可接飞书待办或自建提醒）
每日总结：开关、总结时间与范围（可定时拉数据并让 LLM 总结）
踩坑记录：飞书必须在「权限管理」里开齐 im:message 相关权限（单聊消息、群聊 @ 消息、群内所有消息等），否则订阅了接收消息事件也收不到消息。
你需要做的几步
飞书开放平台
创建企业自建应用，拿到 App ID、App Secret。
开启「机器人」、申请 消息与群组 等权限并发布。
在「事件订阅」里选 Webhook，请求网址填：https://你的域名/feishu/event（或你实际用的 URL）。
订阅「接收消息 v2.0」。
可选：配置 Verification Token、Encrypt Key（代码里已支持解密）。
环境变量
复制 .env.example 为 .env，填齐飞书凭证和大模型 API（如 OPENAI_API_KEY、OPENAI_BASE_URL，国内模型可改成兼容地址）。
本地跑一遍
   npm install   npm run build   npm run dev
用内网穿透（如 ngrok/cpolar）把 http://本机:3000 暴露为公网 URL，把该 URL 填到飞书「请求网址」里做验证和收消息。
云服务器部署
按 docs/DEPLOY.md 用 Nginx 反代、PM2 常驻、HTTPS。
确保飞书「请求网址」指向你服务器的 https://域名/feishu/event。
配置功能开关
GET /admin/config 查看当前配置。
PUT /admin/config 更新（如开启/关闭日程、待办、每日总结及参数）。
生产环境建议给 /admin/* 加鉴权（如 API Key 或登录态）。
流程简述
用户发消息 → 飞书推事件到 POST /feishu/event → 服务先 200 → 异步里解析消息、读配置、调 LLM、按意图走「日程/待办/每日总结」等 → 用飞书「回复消息」API 把结果发回用户。
日程/待办/每日总结的具体飞书 API 调用（创建日程、创建待办、定时推送总结）在 src/features/ 里留了 TODO，你按飞书文档把对应接口接上即可；当前会先返回「功能已开启」的说明文案。
